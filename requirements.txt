# Runtime dependencies for deployment.
#
# pyproject.toml remains the source of truth for local development. This file
# exists because Railway's Nixpacks builder only auto-installs from a
# requirements.txt, Poetry, or PDM layout — a plain PEP-621 + hatchling
# pyproject can build with no dependencies installed at all, and the failure
# surfaces as a confusing ImportError at boot rather than a build error.
#
# Versions are PINNED, not ranged. With ranges, pip's resolver backtracks
# through large numbers of langchain/langgraph combinations and the build can
# appear to hang for many minutes. These are the exact versions the 267 local
# tests run against, so the deployed app matches what was verified.
#
# To update: bump locally, run the tests, then regenerate this file.
